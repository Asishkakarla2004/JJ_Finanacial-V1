# JJ Financial Services

A testing/demo loan web application.

## Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python + Flask
- Data: Random/sample data only
- Database: Not required

## Features
- Home, History and Contact Us pages
- Mission and Vision section
- Six loan categories
- Auto-moving recent loan cards every 3 seconds
- Loan history page with multiple records
- EMI calculator using reducing-balance formula
- Contact form connected to a Flask API
- Responsive design

## Requirements
Python 3.9+ recommended.

## Run on Windows

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Then open:
http://127.0.0.1:5000

## Port
5000
